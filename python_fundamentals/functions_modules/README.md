# islower

Función que determina si un carácter es una letra minúscula mediante su valor ASCII.

Utiliza `ord()` para comprobar si el carácter se encuentra entre los valores 97 (`a`) y 122 (`z`).

Devuelve `True` si es una letra minúscula y `False` en caso contrario

# uppercase

Función que recibe una cadena e texto y la imprime en mayúscula.

Conserva los números, espacios y signos de puntuación sin moficaciones.

El resultado se imprime seguido de un salto de línea. La función no devuelve ningúalor.
