# islower

Función que recibe un carácter y determina si es una letra minúscula del alfabeto inglés.

Devuelve `True` si es una letra minúscula y `False` en caso contrario.

# uppercase

Función que recibe una cadena de texto e imprime sus letras minúsculas convertidas a mayúsculas.

Conserva los números, espacios, signos de puntuación y demás caracteres sin modificaciones.

Imprime el resultado seguido de un salto de línea y no devuelve ningún valor.

# print_last_digit

Función que recibe un número entero y obtiene su ltimo dígito, independientemente del signo del número original.

Imprime el dígito sin texto adicional ni salto de línea y devuelve su valor como un entero entre 0 y 9.

# pow

Función que recibe dos números, una base y un exponente, y calcula la potencia correspondiente.

Admite exponentes positivos, negativos y cero. Devuelve el resultado sin imprimirlo.

# add

Programa que importa una función de suma desde otro módulo y calcula el resultado de sumar dos números.

Asigna los valores 1 y 2 a dos variables e imprime `1 + 2 = 3`.

Solo imprime el resultado cuando se ejecuta directamente, sin producir salida al importarlo desde otro programa.
# calculation

Programa que importa cuatro funciones de un módulo de calculadora para realizar operaciones de suma, resta, multiplicación y división.

Utiliza los valores 10 y 5 e imprime el resultado de cada operación en una línea independiente.

Solo se ejecuta cuando se inicia directamente, sin producir resultados al importarlo desde otro programa.
