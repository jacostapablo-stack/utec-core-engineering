# Positive or Negative
Este script genera un número entero aleatorio entre -10 y 10 y determina si es positivo, cero o negativo.
Según el valor obtenido, imprime uno de los siguientes mensajes:
- `<number> is positive`
- `<number> is zero`
- `<number> is negative`
# Last Digit
Este script genera un número entero aleatorio entre -10000 y 10000 y obtiene su último dígito.
Según el valor obtenido, imprime uno de los siguientes mensajes:
- `Last digit of <number> is <digit> and is greater than 5`
- `Last digit of <number> is <digit> and is 0`
- `Last digit of <number> is <digit> and is less than 6 and not 0`
# Lowercase Alphabet
Este script recorre las letras minúsculas del alfabeto y omite `e` y `q`.
Las letras restantes se acumulan en una cadena y se imprimen en una sola línea, sin espacios y con un único salto de línea al fl.
# Hexadecimal Printing
Este script recorre los números del 0 al 98 y muestra cada valor en formato decimal y hexadecimal.
Cada línea presenta el número decimal seguido de su representación hexadecimal con el prefijo `0x`.
# Two-Digit Numbers
Este script imprime los números del 0 al 99 con formato de dos dígitos.
Los valores se separan por coma y espacio, excepto el último número, que termina con un salto de lí.
