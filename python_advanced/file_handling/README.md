### 0. `read_file(filename="")`: Abre un archivo de texto en UTF-8, lee su contenido y lo imprime en la terminal sin modificarlo ni agregar saltos de línea adicionales

### 1. `write_file(filename="", text="")`: Escribe una cadena de texto en un archivo UTF-8 y devuelve la cantidad de caracteres escritos. Si el archivo no existe, lo crea; si existe, sobrescribe su contenido.
